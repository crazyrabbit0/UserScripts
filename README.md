# UserScripts

UserScripts for browser extensions such as [Tampermonkey](https://www.tampermonkey.net/), [Violentmonkey](https://violentmonkey.github.io/) and [ScriptCat](https://scriptcat.org/). All scripts are also published on [Greasy Fork](https://greasyfork.org/en/users/1223018-crazyrabbit0).

## Installation

1. Install a userscript manager extension (Tampermonkey, Violentmonkey or ScriptCat).
2. Click an **Install** link below, or install from the script's **Greasy Fork** page; the manager opens its install page.
3. Confirm the install. Scripts update automatically from this repository.
